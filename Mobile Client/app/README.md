### Module 1 当前正常处理的云端事宜

#### 1.1 人工导入聊天截图

#### 1.2 给出的行程安排和建议

##### 1.2.1 无事项处理的载入状态：

小宝宝静静的睡觉，然后等待云端的任务。

##### 1.2.2 聚会Mode

- 聚会人员（通过OCR识别到的微信id进行绑定）

- 聚会时间（通过联网服务自动跳转到可能的预约排队，悬浮窗实时显示既定的聚会时间，辅助用户记忆）

- 聚会流程

  - 根据聊天内容，实时的更新聚会的流程（流程的删除要通过弹窗手动确认）

  - 有若干个聚会地点，其中对于每个聚会地点（要做到得功能）

    - 根据聊天内容的记录，实时的更新
      - 示例1：大家在讨论吃火锅，卡片中自动地根据MCP更新出推荐的火锅店，并给出特色菜品图片 + 其他app的截图
      - 示例2：有人说不吃辣的，自动筛选掉辣度高的店铺
      - 提供跳转连接
