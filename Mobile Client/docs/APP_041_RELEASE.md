## 手机更新步骤

1. 打开微光，点击右上角「更新」或「发现更新」。在页面中确认服务地址为`https://agent.qwertyuiopasdf.asia`。如需切换服务地址，先退出当前账号，再从「设置服务地址」入口调整。
2. 点击「检查更新」，应看到「新版0.4.1」。自动检查同一服务地址最多每4小时一次；手动检查可立即获取本次发布。
3. 点击「下载新版」，下载期间保持APP开启。完成后APP会校验大小、SHA256、包名、版本和签名。
4. 点击「安装更新」，按手机系统提示确认安装；首次可能需要允许微光安装更新，返回后再次点击安装即可。
5. 重新打开微光，更新页的「当前版本」应为0.4.1。

没有更新入口或首次安装时，可通过手机浏览器打开[微光内测下载页](https://agent.qwertyuiopasdf.asia/download)，选择「通用内测版0.4.1」。本次为相同包名、相同签名的覆盖更新，不需要先卸载旧版。真实手机的安装流程和数据保留情况仍由本次试用验收。

## 开启和试用采集

1. 登录后进入「云端事项」，创建或选择目标事项，点击「允许自动记录到此事项」。
2. 通过系统聊天采集权限入口，在系统页面手动启用「微光聊天记录」；已开启时可查看权限状态。
3. 返回微信或QQ聊天页，检查是否出现悬浮窗。浮窗应显示绑定事项、采集/同步状态和暂停、结束按钮。
4. 分别试用同页新消息、滚动、暂停后继续，以及结束采集；再回到微光检查新增材料和Agent任务。模型方案需用户确认后才更新正式状态。

当前只对用户正在查看的微信/QQ窗口触发采集，原始截图不上传。不同手机系统可能调整服务入口或后台管理方式，权限由用户在系统中手动操作。
