# ScreenMind 开发日志

本日志记录移动端、云端 Agent、记忆、接口、验证和部署决策。2026-11-18 首次集中补录。历史条目使用验收文档记载的日期，GitHub 链接提供相应版本的提交证据。若实际开发日期无法追溯，标为补记或记录可核实的日期范围。

以后在同一份文件顶部追加当天记录，随相关代码一起提交或由团队在 GitHub 上提 PR。每条记录写清日期、改动或决策、验证环境和结果、待确认事项。实测注明真实模型或模拟、真实或合成材料以及样本数。部署另写目标版本和健康检查，未发布的代码标为本地验证。日志仅引用脱敏证据。

## 2026-11-26 · 修复聚会日期错位

- Cloud Agent 根据线索中的消息发送时间换算相对日期，将带时区的开始时间随方案版本保存。确认后，Android 首页时间轴、事项详情和方案看板读取同一时间。后续只修改参与情况时保留已确认的日期。
- 用合成材料验证 11 月 26 日周四发出的「周六 18:30」，在 11 月 30 日导入后依然安排在 11 月 28 日周六 18:30。时间证据不足时显示「日期待确认」，暂不生成倒计时。历史记录只有相对日期且无已确认时间时需补充具体日期。
- 本地通过移动网关 49 项、Cloud Agent 74 项、Android 24 项单元测试。本次为本地验证。

## 2026-11-25 · 首页第二批首段交通与天气联调

- 接入选城天气、同名地点搜索与确认、相邻日程步行估算。第一轮使用六个大陆城市和 5 分钟缓冲。地点可独立选搜索城市，日程重叠、地点缺失及路线暂不可用各有自然语言反馈。
- 首页和事件流读取现有结果，天气失败后在界面保持暂不可用，用户主动刷新时再试。真实适配器通过服务端的 `SCREENMIND_AMAP_WEB_KEY` 开启，本地环境没有该密钥。本次使用高德响应替身，真实供应商覆盖与调用待验证。
- 47 项网关测试、20 项 Android 单元测试、桌面推演 21 个场景共 79 步通过。在 Android 15 调试包实测手选城市、区分同名入口、估算步行、天气及路线超时。25 分钟的空档遇到 23 分钟步行和 5 分钟缓冲，提示还差 3 分钟。[第二批接口及实现](home-card-phase-two.md#首段本地实现)

## 2026-11-25 · 首页与卡片时间、状态及写回一致性

- 首页、详情、归档和 Android 兼容卡片统一使用结构化开始、结束、时长、全天和完成时间。日期按 UTC+08:00 查询和分组，保留源时间偏移。旧格式日历范围也能恢复结束时间。空档示例的首页、详情与结束时间统一到 30 分钟。
- 进行中的安排显示结束倒计时。顺延保留时长并可跨午夜，返程卡按独立日期归组。可唯一匹配的同日出票线索更新原卡，同时保留来源。完成动作可安全重试，查看线索列表与旧版建议卡时使用读事务，避免同步期间占用写锁。
- 在 Windows 本地网关和 Android 15 调试包上验证。44 项网关测试、20 项 Android 单元测试、21 个桌面场景共 79 步通过。用合成日历与空档卡复测结束倒计时、详情、实时下发、事件流重连与提醒写回。[接口清单](home-card-api.md)
- 真实天气、附近路线、实时报价及交易凭证仍需各自的数据源与联调。本轮是本地验收。

## 2026-11-18 · Android 首页与云端事项蓝色主题

- Android 使用 Kotlin 与 Jetpack Compose，以原生组件承接现有 OCR、系统授权和事项流程。Web 工作台通过 React 与 Astryx 使用对应的设计规范。 [Android 官方 Compose-first 指导](https://developer.android.com/develop/ui/compose/first)
- 首页和云端事项共用蓝色深浅两套配色、本地 ScreenMind Rounded 字体、圆角卡片、状态徽标、表单和主次按钮。首页集中截图导入与云端入口，云端事项将创建、选择、证据、任务结果和方案看板分组。线索整行可点选，创建或提交时收起键盘，候选方案继续用独立状态标识。 [Android 工作台主题](../../Mobile%20Client/app/src/main/java/cn/weiguang/app/ui/WorkspaceTheme.kt) · [Web 工作台主题](../frontend/src/theme.css)

## 2026-11-18 · 方案卡片意见与跨端回归

- 公网 0.4.3 安装包在 Android 15 模拟器完成登录、查看聚会候选和已确认方案、手机确认后网页读取 v2。费用由 ¥86.00 调整至 ¥98.29。独立的合成聊天应用再验证同一应用内切换无关会话，识别结果仅留在本机且未绑定事项。测试后清理合成云端账号。
- 本地加入卡片意见接口。意见绑定当前事项版本及卡片，待确认卡片额外校验任务版本。相同提交重放复用原任务，过期意见提示刷新，提交后正式方案仍须单独确认。
- 网页和 App 的卡片详情增加独立的意见入口，手机侧增加页面渐进过渡。跨账号、过期版本、重复提交与正式状态隔离通过接口验证。本轮交互和动效为本地开发。
- Edge 本地看板的滑动帧间隔 P95 为 16.8 ms。Android 15 的 60 Hz 软件渲染模拟器上，热身后连续切页 219 帧中有 18 帧错过截止时间（8.22%）。手机滑动、候选显示和页面返回的交互回归通过，稳定高刷新率仍须优化并在真机验证。
- 旅行插件预留独立的厂商动作。跳转、资源比价和订单分别验收，正式预订需核验供应商权限、实时金额与用户授权。

## 2026-11-11 · 记忆机制、辅助委派和部署 · 补记

- 增加可追溯的 SQLite 词法检索、结构化抽取和查询规划实验模式。辅助 Agent 审阅限于显式传入的来源，正式状态仍走用户确认。
- SimpleMem 机制对照使用 4 道合成题，词法与抽取加规划均找齐 6 组必要来源，后者增加 40 次调用。Qwen 本机实验的 32 个有答案问题，取前 3 条时找齐证据分别为向量 32/32、词法 26/32，当前非量化 Qwen 的峰值常驻内存为 3.73 GiB，2 GB 服务器保留轻量词法方案。两组统计测量证据召回。
- Ubuntu 部署完成 HTTPS、systemd 拉起、备份恢复与真实模型验证。
