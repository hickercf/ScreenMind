# 樱花粉 Android 前端的数据就绪度

核对日期为 2026-11-26。范围为 ScreenMind 樱花粉概念稿和当前 AuraFlow 工作区的 Android 首页、详情、Cloud、线索和我的。使用本地网关、合成账号和模拟模型，另核对 Android 实际读取和渲染的字段。

## 结论

现有接口可以支撑首页时间轴、基础日程详情、线索核对、Cloud 待确认和聚会看板。聚会日期错位已在本地修复。概念稿中的完整聚会流程、按步骤滚动的云端动态、附近推荐和真实交易凭证仍有数据缺口。

## 逐页对照

| 设计效果 | 现有数据和来源 | 影响和待补项 |
| --- | --- | --- |
| 首页日期、天气、助手 | `GET /api/v1/home/timeline?clientCapabilities=ANDROID_COMPAT` 提供日期、计数、焦点、`nativeState` 和 `homeContext.weather`。Android 读取本机采集授权与状态来更新助手 | 当前天气支持手选城市，实际温度依赖高德。助手的形象和动效由客户端实现。若需在首页显示云端工作的摘要，需提供关联事项、状态和最近更新时间 |
| 焦点、倒计时和时间轴 | 首页与详情共享事件 ID、确切起止时间、时长、归档状态和来源 ID 及版本。实测跨午夜的 55 分钟日程在两端一致，倒计时指向结束 | 有起止时间时可画时间进度。接口的 `progressRatio` 是清单勾选比例。Android 正式首页还会从兼容数据重排和选择焦点，需统一使用服务端已确认的时间和焦点。App 当前线索保存模型只显式发送起始时间，结束和全天信息需要贯穿编辑、上传和读取 |
| 聚会详情、参与人、费用 | `GET /v1/agent/works/{wid}` 提供人员及状态、时间原文、可选的带时区开始时间 `state.scheduled_at`、地点、固定总价、人均预算及分工。`/plan` 提供候选与确认版本以及四张看板卡 | 可以做参与、退出、人均费用和分工。首页与详情共用已确认的开始时间。详情仍只返回摘要块，尚缺地址和候选地点、带稳定 ID 和起止时间的流程步骤、确认状态及图片来源 |
| Cloud 任务动态、人工确认 | `GET /v1/agent/tasks` 提供任务状态、更新时间和关联事项。任务详情提供候选、澄清和证据引用，`/responses` 处理确认 | 现有 UI 能列出任务最近状态。任务列表最多返回 100 条，客户端据此计数。独立 Cloud Agent 有事件读取和事件流，移动网关未提供对应任务事件接口。要做概念稿的逐步动态，需要可续读的用户可见事件和服务端计数 |
| 线索、纠错和隐私 | `/v1/events` 提供确认正文、来源、版本和可选结构化 OCR。用户批准后才上传。系统权限和采集状态由 Android 提供。组成员与共享由网关提供 | 可展示来源和上传状态。概念稿中的第三方账号绑定、通知自动采集和穿戴数据没有对应的产品数据接口 |
| 通勤、空档、地点推荐 | 已有按关键词查找地点、确认地点、两点步行估算及缓冲。地点搜索返回 ID、名称和地址 | 选地点和看步行提示可以联调。自动推荐仍需要营业时段、图片及来源、预计停留时长、到下一站的通行时间、候选有效期和采纳校验。普通账号的附近刷新实测返回空候选，提交采纳返回 409 |
| 出行、订座、购物和凭证 | 可从已有线索提取班次、席位、购物文字和费用。演示数据可填充价格、路线、清单和模拟凭证 | 正式候选需要实时价格、供应商和有效期。出票、订座、领券需有可核验外部状态和回执。普通线索能带来的业务状态取决于来源，界面应区分「线索显示已出票」与「供应商确认已出票」 |

## 优先补齐

1. **已修复聚会日期错位。** 原先首页仅提取「周六 18:30」的时分，将日期回退到周四。本地回归确认，11 月 26 日周四发出的消息即使在 11 月 30 日导入，确认后仍排在 11 月 28 日周六的时间轴，首页、详情和看板一致。原文只有相对日期且时间证据不足时显示「日期待确认」。结束时间仍由线索或用户提供。
2. **让首页和详情能使用同一个聚会计划。** 复用当前事项和候选版本，详情下发可渲染的参与状态、地址、流程步骤、分工与来源。步骤需要稳定 ID、顺序、名称、可选起止时间、当前状态和下一步可执行动作。前端用现有候选和确认机制区分待确认方案与正式安排。
3. **补 Cloud 的可见事件和计数。** 从现有内部事件映射出适合用户看的排队、收到资料、等待补充、方案可确认及结束状态。每条保留任务 ID、发生时间和续读标识。列表和状态总数由网关返回，客户端可按游标接续，避免逐步进展依赖整页轮询。
4. **先联调高德天气与步行，再做真实供给。** 验证授权环境的城市覆盖、同名地点、超时和空态。附近或餐厅候选确认后，再接只读实时报价和可核验履约。缺少可靠数据时正常显示已有日程和可用操作。

## 本地证据

- 移动网关 48 项测试、Cloud Agent 72 项测试通过。
- 额外接口核对确认跨午夜日程的首页及详情共用起止时间和证据版本。模拟聚会从 8 人减到 7 人，候选阶段确认价保持 ¥86.00，新候选为 ¥98.29，确认后正式计划为 v2。
- 模拟供应商未配置时，天气和地点搜索返回暂不可用。普通账号附近无候选，采纳受限。调用移动网关的任务事件路径返回 404，独立 Cloud Agent 的事件端点由代码确认。
- 本次为契约核对。真实高德请求、供应商报价及履约结果仍需独立实测。
